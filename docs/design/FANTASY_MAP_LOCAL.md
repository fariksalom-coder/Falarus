## Fixed screen / moving map

Toolbar now sits outside the scrolling landscape in a fixed overlay. Native
vertical touch and trackpad scrolling stays confined to the map viewport;
mouse dragging supports the same motion and suppresses accidental clicks after
a drag. The document's scroll is locked while the map is mounted and restored
when leaving. Keyboard scrolling remains native. Scrollbars are hidden.

Browser input validation: wheel moved map 0→500, mouse drag 500→800,
reverse wheel 800→450, touch swipe 450→735 px. The toolbar stayed at
11.6875 px and document scroll at 0 throughout. No runtime errors.
See fantasy-pan-check.json. Local change only.

## Ten-day animated pages (replaces continuous panning)

The viewport now stays at scrollTop 0. One wheel/trackpad gesture, pointer
swipe, arrow key or pager action moves a 480 ms translated map track by exactly
one screen. The track has 19 scenes (1–10 through 181–182); offscreen scenes
are inert so keyboard focus cannot accidentally scroll the document. Long
trackpad momentum is consumed once per gesture. Previous/next controls and
stage jumps are available. Reduced motion disables the animation.

Landscape desktop layout uses a wider map and readable lesson rows; portrait
layouts fit one scene in the screen. An overflowing lesson card can scroll
internally without changing the map page. No production deployment or push.
Validation: map-pages-check.json covers 390×844, 768×1024, 1024×768,
1366×768 and 1440×900, wheel forward/back, fixed header/document, touch swipe,
pager and last-page navigation. No browser errors.

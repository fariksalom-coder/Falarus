# Поиск лидов

Поле «Telefon, ism yoki familiya…» находится на странице лидов в обоих видах — доска и список. Ищет по имени, фамилии, полному имени в любом порядке и части телефонного номера. Регистр и лишние пробелы не влияют; у телефона игнорируются +, скобки, пробелы и дефисы. Символы `%`, `_` и `\` воспринимаются буквально. Поиск работает вместе с фильтрами и сохраняется в URL. Оператор видит только свои лиды.

API остаётся прежним: `GET /api/sales-crm/leads?q=...`. Дополнительные миграции для поиска не требуются.

Проверка: `node --import tsx --test tests/salesCrmSearch.test.ts`.

Локальный интерфейс с временной БД: `npm run build`, затем `node --import tsx scripts/dev/salesCrmSearchPreview.ts`, открыть `http://127.0.0.1:5187/leads`. Учётная запись `search-qa`, пароль `Temporary-search-123` существуют только в памяти этого локального процесса. Остановка процесса удаляет тестовые аккаунты и лиды. Никогда не подключать этот preview к production.

Проверено 21 сентября 2026: реальный login API временного оператора; имя/фамилия/полное имя в обоих порядках; телефон с форматированием и последние 4 цифры; пустая выдача; очистка; список/доска; сохранение после перезагрузки; задержанный старый ответ не заменяет новую выдачу; доступ без токена 401; подмена operatorId не раскрывает чужие лиды; мобильный экран 390×844 и desktop 1365×900; без JS exceptions. Локальные и release lint/build прошли.

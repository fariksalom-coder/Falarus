# Тест русского языка и скидки

Опубликовано 19 сентября 2026: https://falarus.uz/test-russkogo

Админка: https://falarus.uz/secure-admin-a9k7x4p2/kiosk (существующий вход администратора).

## Открыть локально

```bash
npm run dev:kiosk
```

- Тест: http://127.0.0.1:4175/test-russkogo
- Демонстрационная админка: http://127.0.0.1:4175/preview-admin

Этот сервер слушает только localhost, использует отдельную базу PGlite в памяти и не загружает `.env`. При перезапуске данные удаляются. `/preview-admin` существует только в этом локальном скрипте, а не в основном сервере. Все тестовые участники и купоны остаются в локальной базе.

## Основное приложение

- Публичный путь: `/test-russkogo` (также `/kiosk`).
- Админка: `${VITE_ADMIN_PATH}/kiosk`; по умолчанию `/secure-admin-a9k7x4p2/kiosk`.
- API: `/api/kiosk` и `/api/admin/kiosk`.
- Административные API находятся за существующей проверкой admin JWT и учётной записи в таблице `admins`.
- Перед запуском основного сервера применить по порядку миграции `db/migrations/185_kiosk_quiz.sql` и `db/migrations/186_kiosk_audience.sql` в целевой PostgreSQL. Существующий `db:push` повторно выполняет все миграции; для этой функции это не требуется.

## Начальные условия (настраиваются в админке)

- На первом экране выбор: детский, подростковый, взрослый. Группа сохраняется в попытке и доступна в статистике.
- Пока все три группы используют общие 10 вопросов и условия курса; отдельных возрастных банков вопросов нет.
- Телефон: +7 по умолчанию, переключение на +998.
- 20 секунд на вопрос, 20% скидки за завершение независимо от балла.
- Срок купона: 15 часов после завершения.
- Курс: «Русский для работы · 182 дня».
- Цена курса не показывается, пока администратор её не задаст.
- Языки интерфейса: русский и узбекский. Сами вопросы — на русском.

Эти начальные условия взяты за основу из HTML-примера; реальные условия акции нужно установить перед публичным запуском. Процент, минимальный балл, срок, время вопроса, названия курса, цена, валюта и код акции редактируются без изменений кода. Снимок условий закрепляется за попыткой в момент её начала.

## Работа с купонами

Посетитель указывает имя и международный номер телефона, даёт согласие на обработку данных и отвечает на вопросы. Согласие на предложения по курсу — отдельное, необязательное; сохраняется в базе и в CSV.

Результат и купон показываются на сайте. Код можно скопировать или скачать текстовым файлом. Автоматической отправки SMS, платёжного QR, онлайн-оплаты и автоматического изменения цены существующей покупки в этой версии нет. Купон предъявляется менеджеру при оформлении соответствующего курса. Менеджер проверяет код через поиск в админке и подтверждает использование с номером заказа или комментарием. Эта отметка не является подтверждением оплаты.

На один телефон выдаётся один купон в рамках кода акции. Повторное прохождение не меняет размер скидки и не продлевает срок. Новый код акции позволяет участвовать заново. Просроченные и использованные купоны нельзя применить повторно.

## Статистика

Показываются попытки, уникальные телефоны, завершения, средний балл, новые купоны и количество использованных из выданных за выбранный период. Графики группируются по календарным дням Ташкента. Незавершённая попытка сохраняется в статистике.

Поиск и фильтр статуса применяются к таблице участников. Верхние показатели относятся к выбранному периоду и возрастной группе. Счётчики трёх групп показывают весь выбранный период. CSV выгружает участников с текущими фильтрами (до 10 000 строк). Для нескольких источников используйте ссылки вида `/test-russkogo?source=kiosk-01` или `?utm_source=telegram`.

## Проверки и ограничения

- Правильные ответы остаются на сервере; браузер получает только текущий вопрос.
- Сервер проверяет время ответа и порядок вопросов. Повторные отправки идемпотентны.
- Итог, выдача купона и запись ответов выполняются в транзакции.
- Купоны защищены уникальностью номера/акции; использование подтверждается атомарно.
- Секрет сессии хранится в `sessionStorage`, в базе хранится только SHA-256. В адресную строку он не попадает.
- Через 2 минуты отсутствия действий экран очищает данные текущего посетителя; уже созданная попытка остаётся в статистике.
- Номер телефона проверяется по формату, но не подтверждается SMS.
- Это короткий тест знаний, не сертификация CEFR.

# Результат: создание урока из видео

Рабочая страница: https://falarus.uz/secure-admin-a9k7x4p2/video-lessons

Выберите «Урок 1 · Знакомство» в списке «Мои уроки». Статус: **черновик**. Предпросмотр открывает существующую «Живую речь», отдельный frontend урока не создаётся.

## Реальный тест

- Видео пользователя: «Мы_говорим_по_русски_Урок_1_Знакомство_1977.mp4», 18 минут 47,933 секунды, 99,3 MiB.
- Полный автоматический цикл распознавания, привязки и перевода: **1330,52 секунды (22 минуты 10,52 секунды)** на CPU.
- **216 предложений, 761 токен слова**, у каждого есть start/end; нулевых/обратных интервалов, нарушений порядка и границ не найдено.
- Все предложения получили отдельный узбекский перевод латиницей.
- Проверены редактор, сохранение, предпросмотр, все 5 скоростей, три режима, подсветка по currentTime, остановка видео в «Говори» и переход между предложениями.
- Публикация проверена в отдельном тестовом хранилище: HTTP 200, видео Range 206; возврат в черновик закрыл публичный доступ (404).
- На рабочем сервере результат оставлен черновиком. Авторизованные получение/экспорт: 200; видео Range: 206; публичный доступ к черновику: 404.
- TypeScript, сборка и 5 специализированных тестов прошли.

Автоматическая проверка меток не подтверждает точность каждой распознанной фразы. Есть ошибки ASR, например «На каком кусе вы учитесь?». Исправления доступны в редакторе с повторной привязкой текста. Машинный оригинал сохранён.

- `src/pages/admin/AdminVideoLessonsPage.tsx` — редактор.

Добавлены подключения маршрутов и пункт админки. Существующий плеер получает lesson через адаптер; его интерфейс сохранён, добавлена навигация по предложениям в режиме «Говори».

## API

База администратора: `/api/admin/video-lessons` (существующая авторизация).

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/` | Список уроков |
| POST | `/upload` | Загрузка видео |
| GET | `/:id` | Черновик и ошибки проверки |
| GET | `/:id/video` | Приватное видео |
| PUT | `/:id` | Сохранить черновик |
| POST | `/:id/process` | Распознавание, перепривязка или перевод |
| POST | `/:id/publish` | Публикация |
| GET | `/:id/export` | Скачать lesson JSON |

Публичные GET: `/api/video-lessons`, `/api/video-lessons/:id`, `/api/video-lessons/:id/video`. Доступны только опубликованные уроки.

## Сервер и хранение

WhisperX запускается только на сервере: `/home/ubuntu/whisperx/.venv/bin/python` → `/home/ubuntu/Falarus/server/videoLessons/prepare_lesson.py`. CPU/int8, 2 потока, модель small. CUDA, diarization и Hugging Face token не используются.

Папка первого урока:
`/home/ubuntu/Falarus/var/video-lessons/065b91d7-53cb-448b-a37f-9744b11c4781/`

- `video.mp4` — исходное видео.
- `lesson.json` — данные урока и служебные поля статуса/версии.
- `recognition.json` — исходный результат WhisperX.
- Кнопка JSON и API `/export` возвращают чистый универсальный lesson без служебной оболочки.

Зависимости проекта, БД, Nginx, SSL и firewall не изменялись. Добавлены необходимые frontend/backend-модули; приложение PM2 перезапущено для включения API, конфигурация PM2 не менялась. Резервная копия исходников: `/home/ubuntu/backups/video-lessons-20260919-145327/`.
